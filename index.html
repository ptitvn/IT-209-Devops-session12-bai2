Tự Động Hóa Phát Hành Docker Image

Hệ thống Continuous Delivery (CD) tự động đóng gói và xuất bản Docker Image lên GitHub Container Registry (GHCR) khi có Git Tag dạng v*.*.*.

  • ✓ Trigger: Tự động kích hoạt khi gắn tag v*.*.*
  • ✓ Registry: GitHub Container Registry (ghcr.io)
  • ✓ Metadata: Tự động đồng bộ tag từ Git qua docker/metadata-action@v5
  • ✓ Build & Push: Đóng gói tối ưu với docker/build-push-action@v5
